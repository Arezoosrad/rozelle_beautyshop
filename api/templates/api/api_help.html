نکات تکمیلی

ساختار پاسخ خطا: 
{
  "ok": false,
  "error": {
    "code": "error_code",
    "message": "پیام خطا"
  }
}
نکات مهم:
  • تمام درخواست‌های نیازمند احراز هویت باید هدر Authorization: Bearer <session_key> داشته باشند.
  • مجوزها بر اساس نقش کاربر و در سطح فیلد اعمال می‌شوند.
  • فیلدهای قابل‌خواندن و نوشتن برای هر کاربر متفاوت است؛ به راهنمای هر مدل مراجعه کنید.
  • شماره موبایل در هر فرمتی پذیرفته و نرمال‌سازی می‌شود.
